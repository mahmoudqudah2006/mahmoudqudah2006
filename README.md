## 🔬 Research

My research combines communication engineering, networking, optimization, and increasingly **AI-driven communication systems**.

Selected research topics include:

- **Adaptive Channel Modulation and Coding for 5G–TSN Integration**
- **Energy-Efficient IEEE 802.15.4 Industrial Wireless Sensor Networks**
- **Machine-Learning-Based Cluster Head Selection in Wireless Sensor Networks**
- **UAV-Assisted Wireless Sensor Networks using ZigBee**
- **IEEE 802.15.4 Superframe Optimization**
- **Monitoring and Notification Systems for Wireless Sensor Networks**

I am particularly interested in extending this work toward **AI-native wireless communication systems** where machine-learning models dynamically optimize communication, networking, and resource-allocation decisions.
